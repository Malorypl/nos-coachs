# Nos coachs

Appli personnelle d'anglais et d'espagnol pour Malory et Jérémy.

**Ouvrir l'appli :** https://malorypl.github.io/nos-coachs/

## L'installer sur le téléphone

- **iPhone (Safari)** : ouvre le lien, touche le bouton Partager, puis « Sur l'écran d'accueil ».
- **Android (Chrome)** : ouvre le lien, menu ⋮, puis « Installer l'application » (ou « Ajouter à l'écran d'accueil »).
- **Ordinateur (Chrome ou Edge)** : l'icône d'installation apparaît à droite de la barre d'adresse.

Une fois ouverte une première fois, l'appli marche aussi sans internet.

## Les progrès

Les progrès sont enregistrés sur l'appareil. Pour les copier d'un appareil à l'autre (ou depuis l'appli Claude) :
sur l'écran « Qui révise ? », touche **Sauvegarder ou restaurer mes progrès**, copie le code, puis colle-le sur l'autre appareil.
Pour chaque coach, c'est toujours la progression la plus avancée qui est gardée : rien n'est perdu.
